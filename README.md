
# 💻 Linguagens de Programação — 2026

Repositório criado para reunir exercícios, atividades práticas e projetos realizados durante as aulas de **Linguagens de Programação**.

**Tecnologias:** C# • C++ • Git • GitHub

---

## 📖 Conteúdos estudados

### 🧩 Aula 02 — Fundamentos da Programação

Nesta etapa foram apresentados os conceitos básicos necessários para começar a desenvolver programas.

* Tipos de dados
* Variáveis e constantes
* Operadores
* Entrada e saída
* Algoritmos básicos

---

### 🌿 Aula 03 — Controle de Versão

Introdução ao Git e ao GitHub para organizar e acompanhar as alterações realizadas nos projetos.

* Git e GitHub
* Repositórios
* Commits
* Branches
* Merge
* Comandos principais

---

### 🔀 Aula 04 — Decisões no Programa

Estudo das estruturas responsáveis por fazer o programa tomar diferentes caminhos de acordo com uma condição.

* `if`
* `else`
* `else if`
* `switch`
* Operadores lógicos
* Operadores relacionais

---

### 🔄 Aula 05 — Repetição

Aprendizado das estruturas utilizadas para executar um determinado trecho de código várias vezes.

* `for`
* `while`
* `do while`
* Controle de repetições
* Laços de programação

---

### ⚙️ Aula 06 — Funções e Métodos

Organização do código através da criação de funções que podem receber informações e retornar resultados.

* Criação de funções
* Parâmetros
* Valores de retorno
* Chamada de funções
* Reutilização de código

---

### 📦 Aula 07 — Vetores e Matrizes

Estudo de estruturas capazes de armazenar vários valores e facilitar a organização dos dados.

* Vetores
* Matrizes
* Índices
* Percorrimento com laços
* Manipulação dos elementos

---

### 🧱 Aula 08 — Estruturas (`struct`)

Utilização de estruturas para reunir diferentes informações relacionadas dentro de uma mesma organização.

* Declaração de `struct`
* Campos
* Organização de dados
* Agrupamento de informações

---

### 📋 Aula 09 — Coleções

Introdução a estruturas dinâmicas utilizadas para armazenar e trabalhar com conjuntos de dados.

* Listas
* Dicionários
* Adição e remoção de elementos
* Acesso aos dados
* `var` no C#
* `auto` no C++

---

## 🛠️ Tecnologias

### C# | C++

As atividades foram desenvolvidas utilizando as linguagens **C#** e **C++**, além das ferramentas **Git** e **GitHub** para versionamento dos projetos.
